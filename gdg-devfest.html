组织与活动

GDG 是什么？DevFest 又是什么？

GDG（Google Developer Groups）是由本地开发者社区自发组织、面向公众的技术社群；DevFest 是 GDG 每年秋冬季的大型开发者嘉年华，涵盖 Android、Web、Cloud、AI、Data 等主题。

GDG 的特点

  • 本地化、开放式、技术驱动
  • 主题多元：Web / 移动 / 云 / AI / 数据
  • 强调实践交流与社区共建

DevFest 的看点

  • 年度热点技术主题与路线
  • Workshop + Talk + Lightning 分享
  • Demo、Hands-on 与本地化案例

本次我关注

  • Chrome DevTools 与自动化
  • MCP 协议与工具链集成
  • 数据科学工作流的工程化
