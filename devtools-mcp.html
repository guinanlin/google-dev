Workshop 主题

Chrome DevTools MCP Server

将浏览器开发者工具能力以 MCP（Model Context Protocol）服务器形式暴露，便于脚本化调试、自动化分析，以及与智能助手协同。

能做什么

  • 打开页面、截屏、抓取页面结构与文本
  • 获取 Network/Console/Performance 等诊断信息
  • 执行脚本、模拟网络/CPU、收集指标

结合场景

  • 端到端可观测：从加载到交互
  • 流水线化性能基准与回归监控
  • 与数据科学/AI 工作流打通

本次 Workshop 目标

  • 建立最小可用的自动化预览与验证
  • 在站点页面中演示典型调用链
  • 为后续扩展留出清晰的工程骨架
